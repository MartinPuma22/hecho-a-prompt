# Imágenes del sitio

Todas están en `shared/assets/img/`. Ahora son ilustraciones sencillas hechas con tu paleta (no son fotos).
**Para cambiarlas, guarda tu imagen con el mismo nombre (.jpg) y reemplaza el archivo.** Se acomodan solas al diseño.

| Archivo | Medida sugerida | Dónde aparece |
|---|---|---|
| hero-inicio.jpg | 1200 x 900 | Inicio, imagen principal |
| curso-1.jpg, curso-2.jpg, curso-3.jpg | 800 x 500 | Tarjetas de Cursos y de Inicio |
| curso-detalle-1.jpg ... 3.jpg | 900 x 700 | Página de cada curso |
| tutorial-1.jpg ... 3.jpg | 800 x 500 | Tutoriales |
| recurso-1.jpg ... 3.jpg | 800 x 500 | Recursos |
| plantilla-1.jpg ... 3.jpg | 800 x 500 | Plantillas |

Para agregar un curso nuevo: copia un bloque en `shared/js/contenido.js`, cambia el `id` y los nombres de imagen.
